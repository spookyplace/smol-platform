# Smol: security

Threat model and controls. **Real** = works the same locally as it would in production. **Simulated** = shown locally, but only meaningful against real AWS/GitHub. **Gap** = not done yet, with the phase that closes it.

## 1. Assets

| Asset | Where |
|---|---|
| Cluster control (cluster-admin) | k3d kubeconfig; ArgoCD's service account |
| Git `main` of `smol-platform` | GitHub. ArgoCD applies whatever is on it, so write access = cluster control |
| GitHub App key + client secret | `~/.config/smol/` (mode 600) → Secret `backstage/backstage-github-app` |
| Backstage database | CNPG `backstage-db`; credentials in the Secret CNPG generates |
| Container images | GHCR `spookyplace/*` (public) |
| Cloud credentials | Floci locally (none real); real AWS only via OIDC (Phase 3+) |

## 2. Trust boundaries

| Boundary | Crossed by |
|---|---|
| Developer → GitHub | `git push`, PRs |
| GitHub → cluster | ArgoCD pulls `smol-platform` (public, anonymous); kubelet pulls images from GHCR |
| CI → GHCR | GitHub Actions with the job's `GITHUB_TOKEN` |
| Backstage → GitHub | GitHub App installation tokens (1 h) |
| Cluster → cloud | Crossplane `ProviderConfig` (`local` = Floci, `aws`) |
| Browser → Backstage / ArgoCD | `kubectl port-forward` (Phase 1); Istio Gateway (Phase 2) |
| Host → cluster | Docker socket, kubeconfig |

## 3. Threats and controls

| Threat | Control | Status |
|---|---|---|
| Push to `main` changes the cluster | Ruleset `protect-main`: no deletion, no force push | Real. Gap: no required review (single maintainer); ruleset JSON vs live settings drift undetected |
| Unreviewed commits applied by ArgoCD | Commit signing + ArgoCD signature verification | Gap: ArgoCD verifies GPG only, not SSH; deferred |
| A team's app deploys outside its namespace or kind | ArgoCD `AppProject` per team | Gap: everything is in `default` (Phase 2) |
| Hand edits drift from git | Automated sync with `selfHeal` (O2) | Real. Child apps revert in ~2 s; `root` only on the periodic reconcile (≤ ~3 min) |
| Git change deletes the database | `Prune=false,Delete=false` on the CNPG `Cluster` | Real (Prune tested; Delete not yet) |
| Tampered or unscanned image runs | SHA-pinned Actions; digest-pinned image in git; Trivy, Cosign, `verifyImages` | Partial: pins real; scanning, signing and admission are Phase 2/4 |
| CI credentials leak | No stored secrets; `GITHUB_TOKEN` scoped to `packages: write` per job; `persist-credentials: false` | Real |
| GitHub App key leak | Minimal permissions (contents + metadata read), selected repos only, `allowedInstallationOwners`; file mode 600; `--from-file` + server-side apply (no copy in annotations) | Real. Key is long-lived (inherent to GitHub Apps); k3d etcd not encrypted at rest |
| Database credentials or traffic exposed | Credentials generated by CNPG, never in git; TLS verified against CNPG's CA; `backstage` role without CREATEDB/superuser | Real |
| Backstage pod escapes or escalates | Restricted securityContext (non-root, no privilege escalation, all caps dropped, read-only rootfs, seccomp); no SA token mounted | Real. Enforcement by Kyverno in Phase 4 |
| Anyone uses the portal | Guest sign-in (`dangerouslyAllowOutsideDevelopment`), allow-all permission policy | Gap: GitHub sign-in + permission framework (Phase 2, O7) |
| ArgoCD admin account misuse | `admin` with generated password, port-forward only | Gap: SSO, disable `admin` (Phase 2) |
| Cross-team network access | Default-deny NetworkPolicies, Istio ambient mTLS | Gap (Phase 2) |
| Cluster API or registry reached from the network | k3d API, ingress and registry bound to `127.0.0.1` | Real for this host. Local registry has no auth |
| Cloud access with stolen keys | No static keys: OIDC for CI, IRSA/Pod Identity for workloads | Simulated: Floci accepts any credentials |

## 4. Host and local-only notes

| Item | Note |
|---|---|
| Docker group | Root-equivalent on the host; accepted for a single-user dev machine |
| k3d kubeconfig | cluster-admin; every `make` call names `--context k3d-smol` so another current context is never touched |
| Floci | Accepts any credentials. No Docker socket mounted. RDS, Lambda and EKS real mode would need it (privileged containers); decided in Phase 3 |
